jsonDB Wire Protocol

The jsonDB Wire Protocol is a simple socket-based, request-response 
style protocol. Clients communicate with the database server through 
a regular TCP/IP socket.

TCP/IP Socket
Clients should connect to the database with a regular TCP/IP socket.

Port
The default port number is 8080.

Messages, Types and Formats
    Standard Message Header
        header {
            messageLength;  // total message size, including this
            id;             // identifier for this message
            responseTo;     // requestID from the original request
                            // (used in responses from the database)
        }
    Standard message 
        MSG {
            header;         // standard message header
            body;           // data
        }
    Request body
        {
            "op": "CREATE | READ | UPDATE | DELETE",
            "payload": {
                "ns": "NAMESPACE",
                "key": "KEY",
                "value": { DATA }
            }
        }
    Response body
        {
            "status": STATUS_CODE,
            "message" : "STATUS_CODE message",
            "payload": { 
                "value": { DATA }
             }
        }

STATUS_CODEs
100: "continue"
200: "ok"
201: "created"
202: "accepted"
400: "bad request"
404: "not found"
408: "request timeout"
411: "length required"
413: "content too large"
500: "internal server error"
501: "not implemented"
503: "service unavailable"
